# 🧠 Quiz

Projeto de quiz desenvolvido para praticar JavaScript e manipulação
do DOM através de uma aplicação interativa de perguntas e respostas.

As perguntas e alternativas são armazenadas em um arquivo JSON externo,
separando os dados da lógica da aplicação.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- JSON

## Funcionalidades

- Exibição de perguntas e alternativas
- Seleção de respostas
- Avanço entre as perguntas
- Verificação das respostas
- Contagem de pontuação
- Barra de progresso
- Tela de resultado ao final do quiz

## Conceitos praticados

- Manipulação do DOM
- Eventos
- Funções
- Arrays
- Objetos
- Estruturas de repetição
- `fetch()`
- JSON
- `JSON.parse()`
- Manipulação de classes CSS
- Atualização dinâmica do conteúdo da página

## Dados

As perguntas do quiz são armazenadas separadamente da lógica
JavaScript em um arquivo JSON.

Isso permite organizar os dados do quiz de forma independente
do código responsável pelo funcionamento da aplicação.
